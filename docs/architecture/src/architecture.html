Inji Interoperability Playground · System architecture

One Docker Compose stack. The playground container holds the UI, the API, the run orchestrator and three independent reference parties; Inji Certify and Inji Verify run next to it. Every HTTP exchange is traced and pushed to the browser over WebSocket.
